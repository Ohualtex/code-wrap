# Code Wrap Privacy Policy

Code Wrap visually wraps classic response code blocks on ChatGPT, Google Gemini,
and Claude. The extension applies its styles locally in your browser. It does
not collect, transmit, sell, or share personal information, chat content, or
browsing history.

Code Wrap saves one on/off preference using the browser's local extension
storage. It uses that preference to remember whether wrapping is enabled.
Uninstalling the extension removes the locally stored preference.

For questions about this policy, contact the project through the
[Code Wrap repository](https://github.com/Ohualtex/code-wrap).
